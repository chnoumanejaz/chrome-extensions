How to test FormPilot
  1. Load the FormPilot extension unpacked in Chrome.
  2. Open this page (via the extension popup or directly).
  3. Look for the blue FP button (no saved data) or preset name chips (saved data exists).
  4. With saved presets: click a preset chip — it fills the form and auto-submits if a submit button exists.
  5. To save new data: click FP or +, then Save Current Form Data.
  6. Clear fields manually and click a preset chip again to verify one-click fill + submit.
  7. Repeat for all three forms — each should get its own fingerprint and presets.
